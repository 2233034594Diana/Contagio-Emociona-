## 🧠 Sobre este Proyecto

Un proyecto de **investigación especializado** en neuropsicología y psicobiología, enfocado en:

- 🎭 **Modelos cognitivos de empatía**
- 🔊 **Contagio emocional** (modelo percepción-acción)
- 🎵 **Reconocimiento de emociones por voz**
- 🇲🇽 **Perspectiva mexicana** en psicobiología aplicada
