# 📚 Bibliografía Relevante - Contagio Emocional

## Visión General

Este directorio contiene la revisión de literatura científica relacionada con el **contagio emocional**, sus mecanismos neurobiológicos, y los factores ambientales (especialmente los paisajes sonoros) que influyen en su transmisión.
